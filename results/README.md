# Results

- `final/`: definitive per-run files and aggregate experiment tables.
- `statistical_analysis/`: corrected pairwise tests, descriptive performance,
  neural seed-44 robustness, and generalisation gaps.
- `explainability_analysis/`: GP operator/program summaries and EOH feature,
  complexity, stability, and recurrence summaries.
- `poster_support/`: source tables and the asset manifest for final figures.
- `search_provenance/`: the best EOH sample metadata for every final fold.

Raw EOH populations and pre-final development outputs are intentionally omitted
from the polished branch. They remain available in earlier Git history.
